## 1. 实施内容概要

根据《侧栏展开收起动画优化：设计与实施计划》的要求，对左侧监控侧栏（`.sidebar`）和右侧 Agent 面板（`.agent-dock`）的展开收起动效进行了全方位的平滑度与分层动效重构：

1. **外壳过渡曲线与节奏统一**：
   - 移除了在应用外壳布局上易造成拖沓和不稳定的弹簧曲线（`--ease-spring`）；
   - 在 `theme.css` 中引入克制稳定的缓动曲线 `--ease-sidebar: cubic-bezier(0.2, 0.8, 0.2, 1)` 及专用时长 `--dur-sidebar: 240ms`、`--dur-sidebar-collapse: 200ms`；
   - 宽度、外边距、边框颜色及投影过渡完全同步，消除侧栏与主终端区域之间的错位与抖动。

2. **内部内容分层进入与退出动效**：
   - `.sidebar-inner` 与 `.agent-dock-inner` 保持稳定固定宽度（分别为 240px 与 360px）；
   - **展开过程**：透明度平滑淡入（`opacity: 0 -> 1`，带 40ms 延迟，避免在过窄宽度下提前露出），并从侧边轻微位移回到原位（左侧向右平移，右侧向左平移）；
   - **收起过程**：透明度快速淡出（120ms），同时向收起方向微移（左侧向左，右侧向右），彻底杜绝内容被容器边缘生硬裁切或逐字截断的现象。

3. **消除边缘厚度与跳动**：
   - 移除了收起状态直接将 `border-width` 设为 `0` 的突变做法；
   - 改为在收起状态平滑淡化 `border-color: transparent` 与 `box-shadow: none`，保持物理边框几何厚度恒定，边缘不再闪烁或跳动；
   - 收起状态配合 `pointer-events: none`、`inert` 与 `aria-hidden`，保证无障碍与焦点安全。

4. **减弱动画模式支持**：
   - 完整适配 `@media (prefers-reduced-motion: reduce)`，系统开启减弱动画时直接瞬时切换，无多余过渡或位移。
