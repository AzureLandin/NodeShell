## 1. 修复概述

针对本地文件拖入 SFTP 文件列表区域后无反应、未触发上传的问题，本次修复遵循推荐方案（前端直连 Wails 官方 `window.runtime.OnFileDrop` 单链路）：

1. **补齐前端 Wails 原生拖放注册链路**：
   - 在 `src/renderer/src/api/bridge.ts` 中扩展 `WailsRuntime` 与 `ApiBridge` 接口声明 `OnFileDrop` 与 `OnFileDropOff`；
   - `WailsBridge` 实现 `onFileDrop(cb)`，内部直接调用 `window.runtime.OnFileDrop((_x, _y, paths) => cb(paths), true)`，在 WebView 中安装 dragover/dragleave/drop 监听并驱动 Windows WebView2 解析真实绝对路径；
   - 支持幂等 `unsubscribe`，清理时调用 `window.runtime.OnFileDropOff()`。
2. **重构 API Adapter 契约**：
   - `src/renderer/src/api/adapter.ts` 中的 `files.onDrop` 改为委托给 `bridge.onFileDrop`；
   - 当底层 Bridge 不支持原生拖放时（例如普通 Web 环境），`api.files.onDrop` 为 `undefined`，允许 SftpPanel 走 DOM 回退或明确报错。
3. **清理过时 Go 中转链路**：
   - 从 `app.go` 中删除了无用的 `filesOnDropEvent`、`registerFileDrop` 以及 `App.startup` 中的调用；
   - 从 `src/shared/types.ts` 中移除了无用的 `IPC.filesOnDrop` 常量；
   - 更新了 `main.go` 中的 DragAndDrop 注释说明。
4. **完善自动化测试覆盖**：
   - 在 `tests/api-adapter.test.ts` 中增加了针对 `WailsBridge.onFileDrop` 注册、参数传递、幂等清理及缺失 runtime 降级的完整单元测试；
   - 在 `tests/ui/sftp.test.tsx` 中增加了原生拖放单次上传、DOM 回退解析上传以及无法解析路径时明确报错（`dropFilesOnly`）的测试。

## 2. 改动文件与代码详情

### 2.1 `src/renderer/src/api/bridge.ts`

```ts
export interface ApiBridge {
  call<T = unknown>(method: string, ...args: unknown[]): Promise<T>
  on<T = unknown>(event: string, cb: (payload: T) => void): () => void
  onFileDrop?(cb: (paths: string[]) => void): (() => void) | undefined
  getPathForFile(file: File): string
}

interface WailsRuntime {
  EventsOn?: (name: string, cb: (...args: unknown[]) => void) => (() => void) | void
  EventsOff?: (name: string) => void
  OnFileDrop?: (
    callback: (x: number, y: number, paths: string[]) => void,
    useDropTarget?: boolean
  ) => void
  OnFileDropOff?: () => void
}

export class WailsBridge implements ApiBridge {
  // ...
  onFileDrop(cb: (paths: string[]) => void): (() => void) | undefined {
    const runtime = wailsWindow().runtime
    if (typeof runtime?.OnFileDrop !== 'function') {
      return undefined
    }
    runtime.OnFileDrop((_x: number, _y: number, paths: string[]) => {
      if (Array.isArray(paths) && paths.length > 0) {
        cb(paths)
      }
    }, true)
    let off = false
    return () => {
      if (off) return
      off = true
      runtime.OnFileDropOff?.()
    }
  }
}
```

### 2.2 `src/renderer/src/api/adapter.ts`

```ts
    files: {
      getPathForFile: (file: File): string => bridge.getPathForFile(file),
      // Native file drops: delegates to Wails window.runtime.OnFileDrop via the bridge.
      // SftpPanel subscribes when present; otherwise it falls back to DOM File.path.
      ...(typeof bridge.onFileDrop === 'function'
        ? {
            onDrop: (cb: (paths: string[]) => void): (() => void) => {
              const unsub = bridge.onFileDrop?.(cb)
              return unsub ?? (() => undefined)
            }
          }
        : {})
    },
```
